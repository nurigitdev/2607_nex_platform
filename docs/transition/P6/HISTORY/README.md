# P6 Design History

This directory preserves superseded P6 transition baselines. Files under
`HISTORY/` are historical evidence and are not current implementation authority.

## Current Authority

The canonical P6 implementation baseline is the v1.1 document set in
`docs/transition/P6/`. Its authority order and required reading sequence are
defined by the canonical `README.md`.

`P6_CA01A_Pre_Implementation_Design_Consistency_Closure_v1.0.md` intentionally
remains in the canonical P6 directory. Although its document version is v1.0,
it is the active design-consistency decision that the v1.1 set incorporates and
references.

`P6_v1.0_to_v1.1_Consistency_Consolidation_Note_v1.0.md` also remains beside the
canonical set as the transition record explaining which v1.0 statements were
superseded.

## Historical Baselines

- `v1.0/` preserves the complete former canonical P6 v1.0 document set,
  including its original README.

Implementation SHALL NOT resolve contracts, schemas, requirements, or design
rules from `HISTORY/` when a canonical v1.1 or higher authority exists.
