## 12. Process Isolation Closure

Decide production P6 execution profile:

### Candidate A
AE Worker hosts `SkillExecutionWorker` in-process.

### Candidate B
AE Worker invokes NSL execution through existing process-isolation adapter.

Decision criteria:

- worker crash containment;
- timeout behavior;
- operational complexity;
- performance;
- evidence/audit continuity.

At minimum, P6 acceptance must prove the AE worker process survives an NSL backend crash/timeout scenario.

## 13. Golden READ Fixture

P6-CA01 SHALL select one READ-only Skill package for closure tests.

Requirements:

- exact version;
- signed NSP for production-profile test;
- deterministic READ Tool contract;
- no WRITE;
- structured output;
- evidence/audit available;
- suitable for prompt→plan→LOCAL_SKILL E2E.

The fixture may use a controlled deterministic provider adapter; it need not introduce Enterprise OS WRITE.

## 14. P6-CA01 Exit Gate

P6-CA01 closes when:

- both repository SHAs are recorded;
- contract matrix is complete;
- transition schemas validate;
- BusinessOperationId/NSLExecutionId ownership is fixed;
- StepResult amendment is explicit;
- exact package/trust projection is fixed;
- v0.1 adapter mapping is fixed;
- status mapper is exhaustive;
- process-isolation profile is selected;
- Golden READ fixture is selected;
- no source implementation is falsely claimed complete.

P6-S2+ may begin only after this closure.
