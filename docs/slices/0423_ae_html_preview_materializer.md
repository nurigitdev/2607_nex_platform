# Slice 0423: AE HTML Preview Materializer

## Scope

Implement the first non-Markdown rendered artifact materializer in AE while
leaving DOCX and PDF export adapters deferred.

## Changes

- Enabled `HTML_PREVIEW` in `ARTIFACT_TRANSFORMER_CATALOG`.
- Added `render_target_formats_from_payload(...)` so render jobs can request
  implemented formats from the artifact handoff while rejecting unsupported or
  deferred formats.
- Added a safe HTML preview transformer that escapes Markdown-derived text and
  emits a small standalone HTML document.
- Updated Markdown render results to produce format-specific payload bytes for
  `MD` and `HTML_PREVIEW`.
- Updated artifact file/link creation to fan out over each rendered file.
- Updated preview/download routes to resolve typed rendered payloads from
  private storage and decode only text formats at the API boundary.

## Decisions

- HTML preview is AE-owned derived output from the validated structured draft
  Markdown, not browser-side conversion and not a CX responsibility.
- The HTML preview transformer intentionally supports only the Markdown shape
  generated by AE today: headings, paragraphs, and citation/list lines.
- `DOCX` and `PDF` remain cataloged but unimplemented. Requests for those
  formats still fail with `ae.render_format_unsupported`.
- Binary payload previews remain blocked at the API boundary until a dedicated
  export/download response shape is added.
